SLSK 2D HD Remake Remaster ~resurrection~

HOW TO START
1. Unzip this folder anywhere (for example your Desktop).
2. Double-click Start.bat.
   - First run only: it installs what it needs (about a minute) and the app opens.
   - If Windows says "Windows protected your PC", click "More info" then "Run anyway".
3. Click "Soulseek login" and type any username and password you want (a new
   Soulseek account is created the first time). Click Save.
4. Get your songs: in the "Convert playlist" tab, press "Open TuneMyMusic" and follow
   the 5 steps (any streaming service works). Click "here" in step 5 to jump to the Song list tab, then paste your
   copied text there with Ctrl+V.
   - Check the first lines look like "Artist - Title". If they are backwards,
     press "Swap Artist / Title".
5. Type a session name and press Start download.
   - The first time, the app downloads the Soulseek engine (about 60 MB).
   - If Windows Firewall asks about "slskd", click "Allow access".

Downloads go to Documents\SLSK 2D HD\<session name> unless you press Browse.
Files are named: 0001 - Artist - Album - Track.FLAC

SAVING AND CONTINUING
File > Save session saves a .slsk file (plain text) with your list, session name,
folder and progress. File > Open session loads it; press Start to continue.
Once a session has a file, it is also saved automatically while running.

IF SOMETHING GOES WRONG
Send me the file app.log (in the data folder, or %APPDATA%\SLSK 2D HD if you use the .exe).
